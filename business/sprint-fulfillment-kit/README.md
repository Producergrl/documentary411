# Funding Sprint Fulfillment Kit

Internal production templates for delivering the $2,500 Funding Package Sprint
(`/funding-sprint`) — built so each of the 4 monthly slots can be fulfilled faster and
more consistently, matching exactly what's promised on the live sales page: a positioning
one-pager, a 12-slide sponsor pitch deck, a 25-brand custom target list, and a 4-email
outreach sequence.

**Not customer-facing.** These are the team's working templates — copy and customize per
client, don't hand them over as-is.

| File | Maps to |
|---|---|
| `01-client-intake-questionnaire.md` | Day 0 — "intake questionnaire" sent after deposit |
| `02-positioning-onepager-template.md` | Days 3–6 deliverable — positioning one-pager |
| `03-pitch-deck-outline-template.md` | Days 3–6 deliverable — 12-slide sponsor pitch deck |
| `04-brand-category-target-map.md` | Days 3–6 deliverable — 25-brand target list, drawn from this 60+ category map |
| `05-brand-outreach-email-sequence-template.md` | Days 8–10 deliverable — 4-email outreach sequence |

A visual, on-brand starting version of the deck and one-pager (built via Gamma) is linked
from `30-DAY-REVENUE-SPRINT.md` once generated — use those as the design starting point,
these markdown files as the content/structure source of truth.
